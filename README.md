# PortfolioHUB

Repositório destinado ao armazenamento de projetos acadêmicos e pessoais.

## Tecnologias utilizadas
- HTML5
- CSS3
- Git
- GitHub

## Objetivo
Criar um portfólio profissional utilizando boas práticas de versionamento e publicação web.

## Funcionalidades
- Página web hospedada no GitHub Pages
- Organização de projetos
- Versionamento com Git
- Integração profissional
